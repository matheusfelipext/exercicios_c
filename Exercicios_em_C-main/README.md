# Exercícios de C — Macros, typedef, sizeof, limits.h e tipos de tamanho fixo

Repositório com a resolução de 5 exercícios de linguagem C.

| Arquivo | Exercício |
|---|---|
| `ex5_macros.c` | Macros (`#define`) |
| `ex6_typedef.c` | Apelidos de tipos com `typedef` |
| `ex7_sizeof.c` | Tamanho dos tipos com `sizeof()` |
| `ex8_limits.c` | Limites da plataforma com `limits.h` |
| `ex9_cadastro_produtos.c` | Programa combinando macros, `typedef` e tipos de tamanho fixo (`uint8_t`, `int32_t`) |

## Como compilar e executar

```bash
gcc ex5_macros.c -o ex5 && ./ex5
gcc ex6_typedef.c -o ex6 && ./ex6
gcc ex7_sizeof.c -o ex7 && ./ex7
gcc ex8_limits.c -o ex8 && ./ex8
gcc ex9_cadastro_produtos.c -o ex9 && ./ex9
```
